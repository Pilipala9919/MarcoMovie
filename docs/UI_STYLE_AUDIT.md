# 界面样式核对 · 0.3.5

应用自身界面采用深色圆角面板、白色焦点、居中文字和短淡入动画。通过全量应用 Java 源码检索与电视定向检查核对，未保留系统 AlertDialog、Toast、PopupMenu 或原生单选框样式调用。

| 范围 | 处理 |
| --- | --- |
| 播放工具与更多子菜单 | PlayerBubble 锚定气泡，独立进度条与紧凑 Dock |
| 设置参数、确认和提示 | AppDialog 自绘标题、列表、勾选和操作按钮 |
| 简介、线路、全部选集、直播线路、文件条目 | 使用统一 AppDialog |
| 收藏管理、清理历史、恢复备份 | 使用统一确认/选择面板 |
| 配置地址与壁纸地址 | AddressInput 圆角输入区与内置遥控键盘，不自动调用系统输入法 |
| 临时结果提示 | 应用内圆角提示条，替换系统 Toast |
| 来源、网盘入口 | 保留自定义来源面板与账号气泡，修正焦点恢复 |
| 全屏与小屏 | 保留同一播放实例及画面承载视图，返回缩到介绍选集页，确认恢复全屏 |
| 首页退出 | 直接结束应用，不弹退出确认 |

系统文件选择器、权限授权界面和第三方网盘/扩展页面由提供方绘制，不能保证它们与应用界面一致。全部页面外观统一不等于所有第三方登录或播放链路都已验证。

本轮设备检查使用合成测试画面，音量为 0。完整检查项目包含在 InteractionProbe.java；旧版本解码格式检查不冒充本轮复测。
