# Marco Movie iOS / iPadOS 0.5.18

应用版本：0.5.18（68）。本次更新 iPhone / iPad 的更新下载、安装工具交接、分层设置和首页 Logo。

## 更新与安装

- 修复玻璃效果加载、透明度切换时重建弹窗内容、导致正在进行的更新检查丢失界面状态的问题。
- 本机版本读取与联网检查独立进行。镜像与 GitHub 备用源各有超时，失败后可重试、取消或打开下载站，不会将检查失败显示为已经是最新版。
- 下载使用更新清单中实际发布的 IPA 地址，不再尝试镜像站上不存在的安装包路径。
- 选择“下载并用巨魔更新”或“下载并自签更新”后，应用自动下载并验证大小和 SHA-256，再打开系统分享菜单。巨魔用户在菜单中选择 TrollStore；证书自签用户选择签名工具导入、签名并安装。
- 分享的是下载后的 IPA 文件，包含 iPad 弹出菜单锚点。取消分享后可再次选择“用巨魔更新”或“用其他应用打开”，已验证的同版本文件可复用。
- 下载进度、连接超时、传输停滞、取消与校验失败均有明确反馈；未完成的临时文件会清理。IPA 同时保存在系统“文件”的 Marco Movie 目录。

## 设置与首页

- 设置首页按外观、浏览、播放、订阅与账号、数据、关于与更新分成六个胶囊入口。
- 二级分类使用抽屉，壁纸、玻璃、画质、倍速、选集等具体内容进入三级页面。支持返回、路径按钮和胶囊选项，旋转屏幕及切换透明度后保留页面与选择。
- 首页 Logo 图标由手机端 24 放大至 36 逻辑像素，扩大点击区域。窄屏自动减少字标占用，保留片源、扫码、搜索及原有五次点击入口。
- 保留 0.5.17 的百度扫码会话完成、旧观看记录或收藏中的玩偶编号恢复等修复。

## 验证范围

本机完整 Flutter 回归 **619 项通过**。新增回归覆盖版本插件不返回、镜像与备用源超时、正文停滞、关闭及重试的迟到响应、玻璃状态变化、IPA 完整性与临时文件清理、巨魔 / 自签自动下载后分享、取消分享后复用，以及小屏、横屏和 iPad 的设置导航与保存。

实际镜像更新源已通过应用同一 Dart 更新客户端读取；本地渲染用于检查布局，不代表 iPhone 实机画面。安装工具交接采用系统文件分享，参考 [share_plus 10.1.4 文档](https://pub.dev/packages/share_plus/versions/10.1.4)和 [TrollStore 文件接收实现](https://github.com/opa334/TrollStore/blob/main/TrollStore/TSSceneDelegate.m)。

IPA 仍为未签名包。系统分享可用的目标取决于设备已经安装的工具；应用不会替用户签名或声称已完成覆盖安装。iPhone 上真实下载、系统分享与巨魔 / 自签覆盖更新仍需实机验收；其他平台安装包不在本次发布范围内。
