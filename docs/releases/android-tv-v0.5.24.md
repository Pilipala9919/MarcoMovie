# Marco Movie Android 电视 / 盒子 0.5.24

发布日期：2026-11-15。版本代码：`85`。本次更新专项修复 HDR10 片源频闪与 HEVC / 杜比视界片源画面偏绿问题，新增全屏播放右上角「已播时长 / 总时长 · 现在时间」悬浮胶囊、首页返回键二次退出确认弹窗、选集详情页豆瓣评分与烂番茄指数展示，并重绘现代悬浮卡片片头片尾专属图标与升级全新金属胶片丝带 M 品牌标识。

## 播放画质与界面交互

- **HDR10 防闪烁保护**：新增 `hdrSessionActive` 持续激活保护，在识别到 HDR10 / HLG / Dolby Vision 片源后全程锁定硬件 `SurfaceView` 直通输出（禁止自动回退切换至 `TextureView`），并在 HDR 播放会话内自动抑制工具条 Alpha 渐变动画与高光重绘，解决部分电视面板因 HDR 模式反复进出导致的画面频闪。
- **HEVC 与杜比视界偏绿色彩修复**：针对缺失色彩元数据的 HEVC 片源自动补齐分辨率自适应 BT.709 / BT.601 默认色彩空间（不覆盖源流已声明的 BT.2020 HDR 元数据），优先选择硬件 HEVC 解码器；准确识别杜比视界 Profile 5（`dvhe.05` / `dvh1.05` 及原始 `dvcC` 配置记录）专有 IPT-PQ-C2 色彩空间，禁止将其错误重标为普通 HEVC，并在设备解码器不支持时给出清晰提示或安全回退，彻底解决画面偏绿偏紫。
- **全屏右上角「已播时长 / 总时长 · 现在时间」胶囊**：全屏播放且工具条与弹层收起时，右上角常驻展示黑曜石半透明圆角胶囊，等宽数字显示当前播放进度、总时长与系统时间；拉起底部播放控制条或任意叠加层时自动隐藏，支持在设置中自由开关。
- **现代悬浮卡片片头/片尾专属图标**：重新设计现代悬浮卡片控制栏中的「片头 `[→`」与「片尾 `←]`」矢量几何图标，与「下一集 `▶|`」及快进快退图标彻底区分。
- **首页返回键二次退出确认**：在电视端首页顶层按遥控器返回键（且无侧栏、抽屉或弹窗打开）时弹出二次确认对话框，默认焦点停留在「继续观看」，防止连续按返回键误退应用。

## 片源详情与品牌视觉

- **选集页豆瓣评分与烂番茄指数**：扩展 CMS 结构化字段与简介文本（兼容 PTGen 全角空格 `◎豆瓣评分　8.9`、「烂番茄新鲜度高达 94%」等描述）双通道提取，自动过滤 `0.0` / `10.0` 等无效占位分值，在选集详情页展示已核验的「豆瓣 ★ X.X」与「烂番茄 XX%」徽标。
- **全新金属胶片丝带 M 品牌图标**：升级电视端桌面图标与 Leanback 横幅 Banner 为黑曜石底金属胶片丝带「M」视觉设计。
