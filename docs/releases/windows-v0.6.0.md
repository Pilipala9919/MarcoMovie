# Marco Movie Windows 0.6.0

发布日期：2026-11-21。应用版本 `0.6.0`（构建号 `76`）。本次大版本更新围绕 Windows 桌面端开展专项体验重构：推出「Quiet Cinema Studio」克制深色影院主题体系、彻底重构 PC 桌面播放页 HUD 与防重复「更多」弹层、升级全幅双模态自适应详情大海报与无边框演职员/线路区、修复 M3U 频道内联请求头与 Windows HTTPS 直播播放、重做左对齐筛选面板与采集源过滤逻辑、新增搜索页「海报 / 列表」布局切换，并实现极速关闭与原生 Windows 系统托盘常驻。

## 更新内容

- **Quiet Cinema Studio 桌面主题与居中自适应导航**：收敛旧版高饱和渐变底色，默认切换至低饱和克制深色影院预设（`obsidian`），保留深浅多套预设并修复浅色纸张主题下标题栏图标与文字对比度；首页顶部导航胶囊改为全宽自适应水平居中。
- **首页等高多卡推荐与高清横屏海报**：统一首页推荐卡片与「最近在看」卡片高度，宽屏拉宽窗口时自动增加推荐剧集卡片数量（不再单卡无限拉长）；修复 `PosterLoader` 中 Bing 宽屏解析正则缺陷并引入严格片名上下文校验，自动拉取真实高清横版海报/剧照，无横图时自动降级为氛围模糊 + 右侧清晰竖版小海报，彻底消除竖图强行拉伸发糊问题。
- **Windows 桌面播放页 HUD 全面重构**：
  - 进度条扩展为全宽桌面级布局；
  - 锁屏按钮移至画面水平中线最左侧；
  - 播放 / 暂停与快进 / 快退按钮居中展示于画面正中，缓冲加载提示胶囊下移至中控按钮下方，杜绝重叠；
  - 将「更多」从触屏横向滑块重构为桌面原生紧凑弹出面板，剔除与主工具栏重复的按钮项（倍速、字幕、定时等），仅保留桌面二线控制项并支持 `Esc` 快捷关闭。
- **沉浸式全幅双模态详情页、真实演员头像与无框极简布局**：
  - 详情页升级为全幅大屏沉浸舞台：有真实高清横图时展示全幅高清宽屏剧照（仅在左下文字与按钮区做局部渐变淡化）；仅有竖版海报时自动切换 Apple TV+ / Infuse 风格「深景深海报氛围模糊背景 + 右侧完整高清 `2:3` 悬浮主海报卡」，兼顾观感与完整构图；
  - 线路选择、选集、正倒序、全部剧集、切换片源与剧情简介整合为收纳展开式按钮组，并移除线路栏与演职员区外层的卡片边框，直接悬浮于影院深色画布；同步清洗部分采集源简介里的 `[展开全部]` 重复片段与站点水印；
  - 新增 `CastAvatarSection` 与 `CastAvatarService`，支持通过百度百科词条卡与 Bing 人像优先解析真实演员照片，并平滑回退姓名首字色标头像。
- **发现页左对齐筛选面板、搜索双视图与筛选链路修复**：
  - 重新设计发现页多维筛选面板（分类 / 类型 / 地区 / 年份），全部筛选行严格左对齐并修复 `WoggNetdiskAdapter`、`CspBridge` 与 MacCMS 服务端及本地筛选未实际生效的问题；
  - 搜索页新增「海报封面 / 列表展示」一键布局切换并记住用户偏好，卡片尺寸随窗口宽度自适应调节。
- **直播源兼容性与 M3U 内联请求头彻底修复**：
  - 修复 `LiveCatalogParser` 丢弃 `#EXTINF:` 行内 `http-user-agent` / `http-referer` / `http-origin` / `http-cookie` 与 `#KODIPROP` 请求头的缺陷，使依赖专属 UA（如 `AptvPlayer-UA`、`iPhone`、`aliplayer`）的 IPTV 频道（央视、卫视、4K 频道等）恢复正常播放；
  - 强制 Windows 端所有 `https://` 直播与点播流走 `LocalMediaLease`（使用系统根证书存储），规避捆绑 `libmpv` 无内置 CA 导致的 mbedTLS 握手失败；补充记录并展示真实上游 HTTP 状态码（如 `HTTP 404 / 403 / 502`），报错时自动清理残留 HUD 提示并隐藏与直播无关的网盘配置入口。
- **点击关闭极速响应与原生 Windows 系统托盘**：
  - 新增原生 Win32 系统托盘图标与右键菜单（`WindowsTrayService` + `prepare_platform.py` 注入），在设置页提供「点击关闭按钮时：直接退出 / 隐藏到右下角系统托盘」选项；
  - 直接退出时改为先瞬时隐藏窗口再并行限超时回收后台会话，彻底消除关闭卡顿。
