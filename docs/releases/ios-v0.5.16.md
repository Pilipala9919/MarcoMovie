# Marco Movie iOS / iPadOS 0.5.16

应用版本：0.5.16（66）。本次修复 0.5.15 的百度扫码、网盘线路显示与重复入口问题；仅更新 iPhone / iPad 安装包。

## 修复

- 百度扫码在一次二维码会话中保留官方 Cookie、设备标识与请求身份，使用适合官方长轮询的超时，并允许扫描后的登录交换重试。完整 BDUSS 与 STOKEN 验证通过后才保存账号并显示已登录。
- 刷新或关闭二维码后，旧请求不能覆盖新会话；超时请求的迟到响应不能写入或删除重试流程的 Cookie。
- 修复原站四条网盘分享共用一个列表容器时，后两条百度分享误标为夸克的问题。保留原分享顺序、文件与真实网盘归属；旧缓存只更正可确认的错误名称。
- 观看记录按唯一线路与原文件恢复；无法确认的旧记录不自动跳转或套用到其他文件。手动选择线路后，主播放按钮遵循当前选择。
- 原生网盘播放异常时只在当前文件内尝试适用画质，不自动跨分享或网盘切线。用户仍可手动切换线路。
- 删除选集区中间重复的“播放线路”、横向线路列表和“网盘扫码”，保留右上角入口。扫码面板默认打开当前线路所属网盘。
