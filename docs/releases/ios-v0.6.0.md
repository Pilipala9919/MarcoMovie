# Marco Movie iOS / iPadOS 0.6.0

发布日期：2026-11-22。应用版本 `0.6.0`（构建号 `86`），基于 Xcode `26.6` / iOS `26` SDK 编译，并继续兼容 iOS / iPadOS `14.0+`（iOS 14–18 与开启「降低透明度」时自动平滑回退高保真毛玻璃组件）。本次大版本更新围绕 iPhone / iPad 端开展系统级沉浸式体验重构：重做无割裂感全幅沉浸海报首页与下拉弹性放大刷新、推出原创 Marco 发现页（含 3 套物理海报墙动效与自定义板块排序开关）、落地零拖影 iOS 18 原生弹簧卡片展开/坍缩转场、升级无框沉浸专题页、上线全能签/巨魔双模无线投屏与半屏电视遥控器、竖屏伴看模式与真实演职员头像、系统浅色/深色自动跟随与液态玻璃强度实时调节，以及随机款式收藏明信片与灵动岛反馈。

## 更新内容

- **无边界全幅沉浸海报首页与弹性下拉刷新重构**：
  - 彻底移除旧版 `SliverAppBar` 折叠挤压裁切逻辑，重构首页顶部推荐为全出血高挑电影画布：海报自动提取边缘氛围色向上渲染至灵动岛与状态栏，并采用外置 `ShaderMask` 多段平滑羽化（上方约 `145pt`、下方约 `265pt` 渐隐至 `0%` 透明度），配合上下溢出的连续氛围光晕与丝滑顶栏滚动渐隐面纱，彻底消除下拉刷新与上下滚动时的硬边界分界线与顶栏裁切问题；
  - 下拉刷新时沉浸海报不再隐藏消失，而是随下拉手势弹性放大并在松手时触发触觉反馈刷新；
  - 首页「分类栏 + 筛选」下移至「片源最新更新」标题下方，顶部阅读层级更加清爽。
- **原创 Marco 发现页体系、3 套物理入场动效与沉浸式专题页**：
  - 打造原创多元发现板块：横版宽屏卡片「光影风向标」、带藤蔓纹饰的合集卡「月度策划」、竖版「热播剧影榜」、堆叠胶囊「灵感片单」、「影业档案室」及「口碑典藏馆」（发现页仅做影单展示，实际起播严格从用户已导入片源中检索匹配）；
  - 点击任意发现合集进入 3 列海报墙时，内置 **黑洞涡旋吸入爆散**、**俄罗斯方块错落堆叠散射**、**重力坠落弹跳展开** 三套物理入场动效；
  - 专题海报墙页面采用无边框沉浸式顶栏（顶部氛围色延展至灵动岛 + 滚动渐隐面纱 + 液态玻璃圆形返回键），移除右上角动效切换按钮，视觉更纯净；
  - 设置页「浏览 → 首页板块与排序」支持逐一开关首页各板块与拖拽调整展示顺序，iOS 端「历史记录」默认关闭（可在设置中随时开启）。
- **零拖影 iOS 原生弹簧海报展开 / 坍缩转场（`PosterExpandRoute`）**：
  - 点击首页、片库或专题墙中的任意海报卡时，通过 `PosterExpandRegistry` 与 `PosterExpandSourceCard` 在飞出期间隐去原位静止卡片并复用单一 `RepaintBoundary` 缓存层 1:1 锁定展开，彻底消除中途双层叠影拖影；
  - 引入基于真实 `SpringSimulation` 的 Apple iOS 18 `.zoom` 弹簧动力学曲线，支持左边缘跟手右滑返回并在松手瞬间无跳变衔接弹簧回弹，精准坍缩回原海报卡片位置。
- **全能签 / 巨魔双模无线投屏与半屏电视遥控器**：
  - 新增纯 Dart 局域网 DLNA / UPnP 发现（SSDP 多播 + 局域网活跃子网探测 + 手动 IP 探测）与 Marco Movie 电视端 Bonjour 发现双模协同，同时兼容 TrollStore（巨魔）与全能签等个人自签工具，支持直连推流与本机局域网中继（适配需 Referer / Cookie / UA 鉴权的片源）；
  - 投屏成功后播放页自动切换至半屏遥控器舞台，支持一键暂停/继续、快进/快退 `15s`、音量调节、拖动进度条、倍速切换、换集与更换/退出设备。
- **iOS 播放页 Liquid Glass 精雕、竖屏伴看模式与演职员头像**：
  - 优化横屏播放页：精简贴合型规格徽章、进度条与低位主工具栏融合为紧凑底部胶囊坞、锁屏键独立居左中线、顶栏右侧精简为「投屏 / 收藏 / 下载」并支持锚定气泡弹层与平滑 HUD 显隐动画；
  - 竖屏播放默认进入伴看模式（顶部 `16:9` 播放视窗 + 下方影片简介、可展开演职员圆形真实头像列表与选集切换），支持一键横屏全屏与物理旋屏自动切换；
  - 详情页与竖屏伴看页同步接入演职员圆形头像组件（支持公开词条与豆瓣公开元数据解析真实演员照片并平滑回退首字色标）。
- **系统浅色 / 深色自动跟随、液态玻璃强度调节与收藏明信片**：
  - 默认主题切换为「跟随系统」，同步完善浅色模式下首页、设置、搜索、发现与播放伴看页的文字与控件对比度；设置页新增液态玻璃透明度/磨砂强度实时滑块；
  - 点击收藏触发复古快门闪光并弹出更宽大、带随机精致边框样式（邮票齿孔、手账票根、胶片画框、波浪花边）且含 Marco 品牌印记的实体质感明信片，收回灵动岛后简洁提示「已收藏 《剧名》」。
