# Marco Movie Android 手机 / 平板 0.5.24

发布日期：2026-11-15。版本代码：`86`。本次更新新增播放器防误触锁屏模式，同步升级 HDR10 防闪烁与 HEVC / 杜比视界偏绿色彩修复、详情页豆瓣评分与烂番茄指数精准提取，以及全新金属胶片丝带 M 自适应品牌图标。

## 播放交互与画质

- **播放器防误触锁屏**：播放控制栏新增一键「锁屏」按钮；开启锁屏后自动收起全部控制条、固定当前屏幕旋转方向，并拦截双击暂停、左右滑动快进快退、上下滑动亮度/音量调节及系统返回键误触；轻触屏幕仅浮现独立「解锁」胶囊按钮（3.5 秒无操作自动隐去）。
- **HDR10 稳定输出与 HEVC / 杜比视界偏绿修复**：在 HDR 会话期间锁定硬件 `SurfaceView` 输出避免频闪；为缺失色彩元数据的 HEVC 流补齐分辨率自适应 BT.709 / BT.601 默认色彩标准并优先启用硬件解码器，准确区分杜比视界 Profile 5 专有色彩空间与 Profile 8.1 / 8.4 向后兼容层，消除画面偏绿偏紫异常。

## 详情展示与品牌视觉

- **详情页豆瓣评分与烂番茄指数**：支持从 CMS 评分字段与简介文本中精准提取真实豆瓣评分与烂番茄新鲜度百分比，过滤 `0.0` / `10.0` 等无效占位分值后在详情页直观展示。
- **全新金属胶片丝带 M 品牌图标**：升级 Android 自适应图标（Adaptive Icon）与单色主题图标（Monochrome Icon）为黑曜石底金属胶片丝带「M」视觉设计。
