# Marco Movie iOS / iPadOS 0.5.15

发布日期：2026-11-10。应用版本：0.5.15（65）。本次按用户明确授权同步发布到 GitHub 仓库与镜像站；各平台独立推进版本，其他平台安装包不更新。

## 修复

- 修复其他采集线路显示为原插件资源的问题：移除采集源替代和自动跨站混线，WoGG 首页、分类、筛选、搜索与详情使用原站数据；来源配置取自用户导入的已审阅插件或明确配置。
- 接入原分享对应的 UC、百度、阿里和夸克网盘协议。保留原始文件与线路归属，使用稳定文件引用，播放时刷新临时凭据；失效、受限或尚未适配的来源明确提示。
- 修复扫码票据未交换有效账号会话却显示已登录的问题。UC、百度和阿里按各自官方会话字段处理，旧无效占位凭据不再被当作有效登录。
- 补齐目录递归与分页，详情最多三份分享并发读取且保留原线路顺序。目录总数不一致时保留实际返回文件并显示警告，不补成标称集数。
- 完善授权生命周期：切集、退出或账号变化时阻止旧会话继续操作；仍由播放器持有的媒体通道在暂停时保留。需要账号的 UC 媒体通过短期本地 Range 通道读取，账号凭据不交给播放器。
- 原画和转码画质采用实际返回信息，不以线路名或文件名伪造 4K / HDR。阿里和夸克需要转存时仅处理所选原文件，不删除用户已有网盘内容。
