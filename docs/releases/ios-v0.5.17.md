# Marco Movie iOS / iPadOS 0.5.17

应用版本：0.5.17（67）。修复百度扫码确认后未完成网盘登录，以及从旧观看记录或收藏进入玩偶影片时读取失败的问题。本次仅更新 iPhone / iPad 安装包。

## 修复

- 百度扫码使用单次编码的授权回跳地址，正确接收授权跳转和 `pan.baidu.com` 下的会话 Cookie，随后完成网盘 Web 登录并验证真实账号身份。
- 不再仅凭缺少 STOKEN 判定扫码失败；只有官方账号接口确认已登录，且取得有效 BDUSS 时才保存。旧二维码票据仍不能充当账号登录凭据。
- 授权交换成功后的网络重试沿用该次会话，避免重复使用一次性二维码票据。刷新、关闭、超时及跨域 Cookie 隔离规则继续保留。
- 旧观看记录或收藏的玩偶编号失效、或指向其他影片时，只在同一原源内按片名和可用年份查找。只有唯一匹配且详情复核一致时才加载原分享；重名、年份冲突或没有结果时明确提示重新选择。
- 重新匹配条目后显示提示，请重新选择对应原文件播放；不把旧来源的集数或进度直接套到新文件。
- 优先使用原订阅同一域名的 HTTPS 地址，保留原地址回退。不会拼入其他采集站线路。
- 保留 0.5.16 的线路归属校正、当前网盘扫码入口和选集区重复按钮清理。

本机完整 Flutter 回归 **595 项通过**；受影响代码及测试静态分析 **0 error / 0 warning**。回归覆盖网盘会话分阶段返回、域名与路径隔离、重定向、失败重试、无效账号拒绝、超时迟到响应、旧影片编号恢复、同名歧义及错片拒绝。
