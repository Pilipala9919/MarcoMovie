# 夸克账户与已有文件播放

当前实现位于共享 Flutter 客户端，iPhone/iPad、macOS、Windows 复用同一逻辑。Android 原生客户端仍使用已有插件账户入口，不能据此记录为 Android 新增协议已验收。

从首页网盘或设置中的账号中心选择夸克，扫码并在夸克 App 确认后，应用交换真实 Cookie、验证 PC 网盘账户，再保存结构化会话。手动输入 Cookie 同样先验证。旧版的占位凭据不再被视为已登录；旧真实 Cookie 可以重新验证后使用。

扫码成功依赖服务器返回的 Cookie 和有效账户响应，点击“检查登录状态”只重新查询，不会自行生成凭据。二维码使用本地 QR 编码，不把登录挑战发给第三方图片服务。退出、刷新或切换账户后，迟到的请求不会覆盖当前状态。

“浏览网盘视频”列出账户中已有的目录和视频，支持分页、返回上级、长名称及横屏。选择视频后，由固定网盘接口取得原画和实际返回的转码档位，进入现有播放器。影片标识只保存账户隔离键与文件 ID，不包含 Cookie、分享 token 或临时媒体 URL。账号凭据不进入普通备份，也不直接附到任意图片或媒体 CDN。

PC 账户验证成功即可读取已有文件。网盘 Drive ST 是另一种票据；没有取得它时会话仍可用于 PC 接口，`h5Save=false`，不能据此声称 H5 转存已授权。CAS 扫码票据和 Drive ST 不混用。

本轮没有自动转存、创建文件夹或删除用户文件。分享文件 ID 不能当作账户内文件 ID 使用。WoGG 等依赖网盘的来源，仍需接入各自目录与分享解析、转存流程及实际播放验证。

验证分层：账户协议、凭据接线、目录分页、原画与转码、异常及界面竞态已用独立模拟服务和组件测试覆盖；这些结果不等于真实账号扫码或 iPhone 媒体解码通过。实际用户账户、网络和设备播放应单独记录。
