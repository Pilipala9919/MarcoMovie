# 使用指南

## 第一次打开

全新安装没有预装内容。选择“导入我的配置”，填写自行合法获取的配置地址，或选择本地配置文件。地址输入框默认为空；使用过的地址会保存在本机，便于之后更新。导入成功只代表配置可读取，不代表其中每个项目都能播放。

本项目不提供影视资源及配置地址。不要将未知来源的账号凭据或不可信扩展导入电视。

## 首页和遥控操作

方向键移动焦点，确认键打开项目，返回键关闭当前页面或弹窗。首页采用竖版海报和多行分区；“查看全部”和“全部分类”进入更完整的列表。左上“标题＋当前来源”区域可以直接打开来源选择弹窗；从第一排海报按上可到达该区域。

## 继续观看

播放后，首页会显示“继续观看”。记录保留在本机，最多 60 部；点击海报会重新获取播放地址，并恢复对应集数和进度。接近片尾的记录再次打开会从头播放。若原来的来源、线路或集数已经变更，会提示重新选择。

“观看历史”页面可移除单条记录或清空记录；也可从设置的“搜索与数据”进入。覆盖升级保留本机记录，配置备份不包含观看历史。

## 全局搜索和输入

顶部“搜索”是独立页面。输入停顿约 0.65 秒后自动检索，无须点击搜索；“立即搜索”可提前发起。继续输入会取消上一轮并忽略过期结果。内置键盘由遥控器操作，不依赖系统输入法。可以选择中文候选字，也可输入完整拼音或首拼；最终匹配受本地字词典、已学习标题和配置接口能力影响。结果按配置项返回，部分请求失败不会被当作“找到结果”。在设置中可调整检索并发数和等待时间。

## 内容详情

进入影片详情后，左侧展示竖版封面，右侧显示名称、简介和收藏，下方显示线路与选集；不显示首页顶部导航。详情未提供封面时沿用列表封面，无图片时显示占位。用遥控器返回键或左上“返回”回到上一页。

## 播放与字幕

从内容详情选择线路与集数。全屏观看时，单击遥控器确认键直接暂停／继续；上下键同步显示顶部片名与集数、独立进度条和底部紧凑 Dock，焦点先落在进度条。屏幕中央显示播放／暂停操作图形；播放时显示暂停图形，暂停时显示继续播放图形。在进度条上左右键跳转、确认键暂停／继续，向下进入工具按钮。焦点在工具按钮时，确认执行相应操作。返回键先收起 Dock，再返回详情。

Dock 提供选集、线路、下集、倍速、画面、字幕、更多；播放器、解码、音轨、刷新、重播、上一集、片头片尾、弹幕、音效、色彩、循环及播放信息收在“更多”。Dock 内没有单独的暂停按钮。“更多”以及播放子菜单从所选按钮上方展开为圆角气泡；上下滚动选择，返回关闭并恢复原按钮焦点。某些菜单只在播放器与内容实际支持时有效。无法解码时可尝试切换播放内核或解码模式，不能保证每种设备/文件组合都有效。

外挂字幕通过系统文件选择器导入；支持范围取决于当前播放内核。弹幕可加载兼容数据，项目本身不提供弹幕服务。音效处理受设备音频会话支持限制，色彩档位不是 HDR 或专有画质技术的替代品。

## 设置

| 页面 | 操作 |
| --- | --- |
| 首页与壁纸 | 海报列数、行数、分类分区、壁纸、压暗与减少动态效果 |
| 播放与字幕 | 播放器、解码、比例、缓冲、速度、循环、自动下一集、跳过时长、字幕和音画选项 |
| 搜索与数据 | 搜索并发与等待、导入配置、启用扩展、备份还原和清理 |

顶部“网盘”按钮打开从按钮下方展开的账号面板，包含统一登录入口、凭据管理和网盘顺序；设置页不再重复放置账号入口。面板只是调用兼容扩展的入口；未导入支持相应能力的配置时不能登录。账号状态应以服务提供方或扩展的实际提示为准，出现二维码不等于已经登录。

壁纸支持本地图片或图片地址。电视没有系统文件选择器时，本地导入、字幕及备份文件操作可能不可用。图片地址会连接到用户指定的服务器。

## 备份和升级

备份包含配置原文及白名单内的播放/外观偏好，不包含扩展另行保存的登录状态。**配置原文中的令牌、账号或其他敏感字段也会被备份**；不要把备份上传到公开 Issue 或仓库。还原会在确认后替换对应配置和偏好。

覆盖安装应使用相同签名。自行构建的开发签名可能与项目发布包不同；升级前请自行备份必要数据，不能保证通过卸载再安装保留登录状态。

## 常见问题

- **首页没有内容？** 全新安装为空是预期行为。先导入自己的配置；网络失败、空列表和接口变更也会导致无法加载。
- **拼音结果不准确？** 首拼可能有多个含义，试用完整中文或全拼。结果仍依赖用户导入的配置。
- **播放失败？** 检查内容是否仍可访问、是否需要本人登录、设备是否支持其编码；再尝试切换内核。
- **某个设置没有效果？** 部分功能由系统或扩展提供，不能跨设备强制实现。
- **在哪里获取影视资源？** 本项目不提供资源、订阅地址、获取渠道或账号。请自行合法获取。

## 解码组件与排错

从 0.3.3 起，安装包内置音频和 AV1 / VP9 软解码扩展，无需另装组件。优先保留自动解码；在设置中打开“解码组件”检查加载状态，在播放菜单的“播放信息”查看实际使用的解码器。系统播放器不使用这些扩展。网络、账号和临时地址失效不能靠安装解码组件解决。详细范围见 [DECODERS.md](DECODERS.md)。

## 我的收藏

详情页点击“加入收藏”；顶部“收藏”进入收藏页，确认打开最新详情，长按确认或按菜单键可取消收藏。收藏按来源和内容标识区分，最多保留 300 部，保存在本机；覆盖升级保留。来源暂不可用时保留收藏并提示，不存储临时播放链接。当前配置备份不包含收藏和观看历史。
