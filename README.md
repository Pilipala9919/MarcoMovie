## 产品介绍

Marco Movie 希望让大屏电视、随身手机、平板电脑与桌面端上的浏览、搜索和播放同样自然顺手：在电视上以大幅竖版海报与清晰焦点反馈配合遥控器操作；在手机与平板上采用完全独立的触控界面（竖屏底部四栏 Dock、横屏右侧 Dock、原生键盘搜索、剪贴板一键导入、全屏手势播放）；并提供 `flutter/` 跨平台工程覆盖 Windows、macOS、iPhone 与 iPad。应用没有预装片库；第一次打开时，用户需要自行导入有权使用的配置。

这是一个原生 Android 与多平台客户端项目。界面、配置管理、播放控制和本地搜索匹配在设备上运行；本项目不运营影视内容服务。功能和设备兼容性仍在持续完善。

## 能做什么

| 功能 | 当前能力 |
| --- | --- |

| 内容详情与选集 | 电视端左固定大海报、右独立滚动；手机端采用左海报右信息紧凑卡片、可折叠简介、横向滑动线路胶囊、每 50 集自动分组标签、正序/倒序切换与 3 列大拇指触控选集网格 |
| 我的收藏与历史 | 详情页一键收藏；手机端“我的”标签页整合观看历史与我的收藏，支持单条删除与一键清空；数据保存于本机 |

全局搜索的范围是**用户已导入的配置**，不是互联网全网搜索。拼音匹配结合本地字词典和已浏览/搜索过的标题，首拼存在歧义时可改用完整中文。功能存在不代表任意配置或服务都兼容。

## 安装与开始使用

1. 在 [镜像下载页](https://marcotv.wlj9919.top/movie/) 或 [Releases](https://github.com/Pilipala9919/MarcoMovie/releases) 下载 APK 安装包，并核对随附的 SHA-256 文件。
2. 根据设备选择独立安装包：电视/盒子用 `-android-tv.apk`（ARM 32 位），手机/平板用 `-android-mobile.apk`（包含 ARM 32/64 位）；旧 Android 4.0+ 设备选择独立 Lite 包。从 0.5.0 首次升级请手动安装对应设备包，此后进入独立更新通道。Windows / macOS / iOS 见各自发布附件；最低系统声明不代表已通过该设备的实测。每次修复与验证范围见[版本记录](CHANGELOG.md)。
3. 打开应用导入配置：
   - **手机 / 平板端**：直接在首页欢迎卡片输入网址，或复制配置链接/JSON 后点击「📋 一键读取手机剪贴板并导入」，也可选择手机本地 JSON 文件，无需扫码。
   - **电视端**：选择“导入我的配置”，用同一局域网的手机扫码粘贴自行合法获取的配置地址；也可选择遥控输入或本地文件。本项目不提供获取影视资源的方法或地址。
4. 原生 Android 标准版的扩展执行默认开启，可在设置中关闭；仅导入信任的配置。其他平台不等于具备同一插件运行环境。电视端用方向键和确认键操作；手机与平板端使用底部导航栏、系统键盘与全屏播放触控手势操作。
5. 在“设置”中调整解码、倍速、比例和备份选项。需要网盘授权时，应由本人在服务提供方界面完成登录。

同一应用签名的安装包一般可以覆盖升级；自行编译会生成自己的开发签名，不能保证覆盖官方项目发布包。卸载会删除应用本地数据，请先妥善保存必要配置。详细操作见[使用指南](docs/USER_GUIDE.md)。

## 设备与兼容性说明

- 最低 Android 6.0（API 23）；当前主要验证环境为 Android 9、ARM 32 位电视。最低版本声明不等于每台设备均已实测。
- 兼容标准 JSON 内容接口及部分可选扩展形式，原生 Android 标准版扩展默认开启，可在设置中关闭。没有承诺所有配置、网盘、直播列表、编码或第三方服务都可使用。
- 磁力组件属于实验能力，要求 Android 8.0+；已完成本地协议测试，尚不作为所有电视上的稳定视频播放能力宣传。
- DRM 仅传递合法授权相关参数，不绕过授权；尚未完成授权样本的端到端验收。
- 持久媒体缓存、渲染视图切换等仍未完成。部分设置依赖系统文件选择器或扩展实现。

跨端差异和本轮修复状态见[兼容与验证边界](docs/COMPATIBILITY.md)。更多状态见[功能与验证范围](docs/STATUS.md)。遇到问题可提交 [Issue](https://github.com/Pilipala9919/MarcoMovie/issues)，请勿附带账号、Cookie、私有配置地址、二维码或无权分享的内容。

## 项目结构与开发

```text
android/src/main/       原生 Android 应用代码（手机 / 平板与电视独立分包）、输入词典与第三方许可
android/tests/          本地模拟数据测试，不包含真实影视配置
android/*dependencies.json  固定版本依赖及校验摘要
flutter/                跨平台客户端工程（覆盖 Windows / macOS / iPhone / iPad，与安卓端互通备份）
scripts/               构建、依赖准备、公开内容检查
docs/                  产品、使用、构建、隐私与验证说明
```

当前构建流程基于 Windows、Python 3、JDK 17 与 Android SDK 工具。构建时从依赖发布方下载清单中固定版本的依赖并校验摘要。详见[构建说明](docs/BUILD.md)；不会下载影视配置或内容。
